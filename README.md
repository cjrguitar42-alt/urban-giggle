# Guitar Website

This starter site follows the hand-drawn layout:

1. Title
2. Main photo
3. Four videos
4. Bio
5. Set list
6. Pictures

## File structure

- `index.html` — webpage content
- `style.css` — layout and design
- `images/` — your photos

## Add your photos

Place your image files in the `images` folder and name them:

- `main-photo.jpg`
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

Or change the filenames in `index.html`.

## Add YouTube videos

For a YouTube link like:

`https://www.youtube.com/watch?v=abc123XYZ`

The video ID is:

`abc123XYZ`

Replace `VIDEO_ID_1`, `VIDEO_ID_2`, etc. in `index.html`.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and the `images` folder.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Click **Save**.

GitHub will display the public URL after deployment.
